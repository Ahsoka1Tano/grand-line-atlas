# Grand Line Atlas

Фанатский мир One Piece: коллекционные карточки, команда мечты и приключения на интерактивной карте.

## Текущий этап: Visual Alpha

Реализован первый визуальный этап:

- Три подготовленных арта: Луффи, Зоро и Нами в ранних образах East Blue.
- Шесть демонстрационных изданий и четыре варианта редкости: C / R / SR / SSR.
- Коллекция с поиском, фильтрами, сортировкой, избранным и крупным осмотром.
- Экран боксов и сцена открытия: сундук, раскрытие трёх карт, блики, звуковые акценты.
- Пропуск, повтор сцены, уменьшенная анимация и мобильная компоновка.

## Анимированный морской атлас

Открыть http://127.0.0.1:3000/world или выбрать «Карта мира» в навигации.

- Общий векторный атлас на пергаменте: четыре моря, Red Line, Grand Line и Calm Belt.
- Органические контуры островов, подписи, розы ветров и гравированные ориентиры.
- Движущиеся корабли, морские течения и вращающаяся мельница.
- Приближение к East Blue с пятью игровыми локациями и отдельной панорамой каждого берега.
- Перемещение мышью или пальцем, масштабирование колесом и кнопками; поддержка pinch.
- Управление клавиатурой: стрелки, `+`, `-`, `Home`.
- Выбор локации, предварительный маршрут и анимированное плавание корабля с отменой курса.
- Вход в посещённую локацию и осмотр трёх точек интереса.
- Журнал капитана с сохранением посещений и текущего причала в этом браузере.

География — авторская схема мира по мотивам One Piece; масштабы условны. Плавание не выдаёт наград и не связано с серверной экономикой.

Бокс имеет фиксированный состав. Полученные экземпляры добавляются только в демо-коллекцию текущего сеанса. Повтор просмотра уже добавленного бокса не выдаёт их повторно. Избранное и настройка звука сохраняются локально в браузере.

Авторизация, серверная коллекция, валюта и бои запланированы следующими этапами. Навигация к ещё не реализованной команде отключена.

## Запуск

Требуется Node.js 22+ и pnpm.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Открыть http://127.0.0.1:3000.

```sh
pnpm typecheck
pnpm build
pnpm start
```

Версии зависимостей зафиксированы в pnpm-lock.yaml. Визуальный этап использует Next.js, React, TypeScript, Motion, Lucide и собственные CSS-компоненты. Игровой движок и база пока не подключены.
